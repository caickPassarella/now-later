# now-later

A personal memory aid app. Built to help with focus and memory — quickly log anything worth remembering, then look it up later by browsing or searching.

## Features

- **Thoughts** — log anything on your mind that you'd like to remember later; searchable so you can look back at what you were thinking on any given day
- **Daily** — log activities as you do them throughout the day; browse past days with forward/back navigation
- **Trash** — soft-deleted entries are kept and can be permanently removed from the deleted page
- Persistent storage via Postgres (Neon) + Prisma
- Monitoring via AppSignal

## Stack

- [Next.js](https://nextjs.org/) 16 (App Router)
- [Chakra UI](https://chakra-ui.com/) v3
- [Prisma](https://www.prisma.io/) 7 with [Postgres](https://neon.tech/) (Neon)
- [AppSignal](https://www.appsignal.com/) for error tracking and metrics

## Getting started

**1. Install dependencies**

```bash
npm install
```

**2. Set up environment variables**

Copy `.env.example` to `.env` and fill in your credentials:

```bash
cp .env.example .env
```

You'll need a Postgres connection string — e.g. from the [Neon dashboard](https://neon.tech) — set as `DATABASE_URL`.

**3. Generate the Prisma client**

```bash
npx prisma generate
```

This generates the TypeScript client from the schema. Required before the app will compile.

**4. Apply database migrations**

```bash
npx prisma migrate deploy
```

This applies any pending migrations (including indexes) to your Postgres database.

**5. Start the dev server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Database

The app stores data in Postgres (hosted on [Neon](https://neon.tech)), accessed through Prisma. Connection details live in `DATABASE_URL` (see `.env.example`).

**Main files:**

- [`src/prisma/schema.prisma`](src/prisma/schema.prisma) — the data model (currently `Thought` and `Daily`). Edit this to add/change fields or tables.
- [`src/prisma/migrations/`](src/prisma/migrations) — generated SQL migration history; created automatically, not edited by hand.
- [`prisma.config.ts`](prisma.config.ts) — tells the Prisma CLI (`migrate`, `generate`, etc.) which database to connect to.
- [`src/lib/db.ts`](src/lib/db.ts) — creates the single shared `PrismaClient` instance (via the `@prisma/adapter-pg` driver adapter) that the rest of the app imports to run queries.
- [`src/lib/thoughts.ts`](src/lib/thoughts.ts) / [`src/lib/daily.ts`](src/lib/daily.ts) — the actual queries (fetch, add, soft-delete, permanently delete) for each model.
- `src/app/generated/prisma/` — the Prisma Client code generated from the schema; regenerated by `npx prisma generate`, never edited by hand.

**Changing the schema:**

1. Edit `src/prisma/schema.prisma`.
2. Run `npx prisma migrate dev --name <short-description>` — this creates a migration file, applies it to your DB, and regenerates the client.
3. Commit the new folder under `src/prisma/migrations/` along with your code changes.
4. In other environments (e.g. production), apply pending migrations with `npx prisma migrate deploy`.
